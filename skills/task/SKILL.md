# Task

The member who typed /task wants a task on the board. The text after /task says what it is about. With no text, it is about what you discussed last. If you cannot tell what the task is, ask the member one question first.

The quote: the member's words in quotes, with their name (the name in brackets at the start of their message, without the device) and the date.

1. Room: the room the member names, else your room.
2. Search the open tasks of that room, backlog included (see the tasks reference page). If one covers the same work, add the quote to it, and reply in one line: added to existing task, its id and its title.
3. Otherwise file a new task in that room:
   - Title: one short line that says the problem or the want.
   - Description: the quote, then the context from this conversation that a reader without it needs: what happened, where, and the links or files.
   - Set a priority or an assignee only when the member gives one.
     Reply in one line: the task id and its title.
4. Do not start the work.
