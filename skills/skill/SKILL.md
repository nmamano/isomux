# Skill

The member who typed /skill wants a skill added or changed. The text after /skill says what it does. With no text, it is what you discussed last. If you cannot tell what the skill is, ask the member one question first.

1. Read the skills catalog (see the skills reference page). Change an existing skill only when the member names it, or when it is a user skill that clearly does the same job. Keep what it already does, unless the member asks otherwise. If it is not editable, ask the member whether to make a new skill with another name. Otherwise create a new skill.
2. Keep it short and on one job, with a description that says what it does and when to use it.
3. Save it. Reply in one line: the skill's name, and whether it is new or changed.
4. If the office refuses the save because this agent may not edit skills, do not write the file another way. Give the member:
   - For a new skill: the name, the description and the instructions as three separate blocks, then one line: paste them in New skill on the Skills page.
   - For a change: the whole new file, then one line: open that skill on the Skills page and replace its text.
