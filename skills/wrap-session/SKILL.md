# Wrap Session

Review the conversation and the work you changed. Check for uncommitted or unpushed changes, unfinished work, deferred decisions, and promised actions that remain open.

A loose end is something that still needs an action by an agent or a human. Report only those. For each one, propose one concrete next action, such as creating an Isomux task, recording a durable fact in the right project document or memory, writing a handoff brief, committing, pushing, deploying, or verifying a deployment. Ask before an action that still needs member approval.

If you also want to tell the member something that needs no action, put it under the heading "Informative only, not actionable". Do not invent items for that heading to have something there.

If nothing remains, say so in one line and end the session.
