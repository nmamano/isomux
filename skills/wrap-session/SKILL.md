# Wrap Session

Review the conversation and the work you changed. Check for uncommitted or unpushed changes, unfinished work, deferred decisions, and promised actions that remain open.

Report only real loose ends. For each one, propose one concrete next action, such as creating an Isomux task, recording a durable fact in the right project document or memory, writing a handoff brief, committing, pushing, deploying, or verifying a deployment. Ask before an action that still needs member approval.

If nothing remains, say so in one line and end the session.
