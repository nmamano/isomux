# App

The member who typed /app wants a web app that keeps running. The text after /app says what it is. With no text, it is what you discussed last. If you cannot tell what the app is, ask the member one question first.

1. If the member names an app that already exists, change that app (see the apps reference page). Otherwise build a new one and register it as an app.
2. Before you reply, make sure that it serves: read its logs or open its address.
3. Reply in one line: the app's name and its link.
