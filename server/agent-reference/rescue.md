# Rescue

When your manager is an office owner, you can export the office's content and lock the office. Any other agent gets 403.

Start an export only when a member or an agent with the same manager asks for one, or a member says yes: `POST /api/office/exports` with `{}`, then read `GET /api/office/exports/:id` until `state` is `ready` or `failed`. Give the owner the download link: the office address plus `/api/office/exports/:id/download`. Only an owner's browser session downloads it; you get 403. The file is deleted one hour after it is ready.

Lock the office with `POST /api/office/lockdown` and `{reason}`, only after a member gave the reason and a clear yes. The office signs everyone out, ends every agent (you included), and then stops or shows only a locked page. Only `unlock` on the office's machine ends the lock.

An owner moves the office to another machine with a move code from Settings > Move office in their browser; you cannot get the code. `GET /api/office/move` shows the move. Cancel it with `DELETE /api/office/move` only when a member or an agent with the same manager asks. On the new machine, the owner starts the move in and agrees to the lock from their browser. `GET /api/office/move-in` shows it; `POST /api/office/move-in/preflight` checks the old office again, `POST /api/office/move-in/pull` pulls it again after a failure, and `DELETE /api/office/move-in` cancels it. Use these three only when a member or an agent with the same manager asks.

## Route contract

`POST /api/office/exports` returns 202 `{id}`, or 409 while an export runs. A new export deletes the previous file. `GET /api/office/exports/:id` returns `{state,bytes?,error?,expiresAt?}`: `state` is `running`, `ready` or `failed`; `expiresAt` is epoch ms. An unknown id returns 404. `POST /api/office/lockdown` takes a `reason` of 1 to 500 characters (422 otherwise) and returns 202 `{locked:true}`; every later request gets the locked page. 500 means the lock marker could not be written, and nothing changed. `GET /api/office/move` returns `{state,expiresAt?,pairedAt?,newBox?}`: `state` is `none`, `code` (waiting for the new machine), `paired` or `move` (locked for the move). `DELETE /api/office/move` returns `{cancelled}`, or 409 once the office is locked for the move. `GET /api/office/move-in` returns `{phase}`. In `none` (no move comes in), `blocker` is null or `{code,message,extra?}`, why this office cannot take a move in. During a move it adds `oldOrigin`, `oldOfficeLocked` (a cancel leaves the old office locked), `preflight`, `progress`, `result` (`missing` lists what did not come) and `error` with `retryable`. In `moved` it gives `report` and `asidePath`, the folder that holds the office set aside, which `DELETE /api/office/move-in` removes. `POST /api/office/move-in/preflight` (phase `confirm`) and `POST /api/office/move-in/pull` (a retryable `failed`) return 202 with the status, or 409. `DELETE /api/office/move-in` returns `{cancelled, oldOfficeLocked}`.
