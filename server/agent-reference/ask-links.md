# Ask links

An ask's `link` opens one page from a button on the card.

For a page outside the office, send the https URL of the exact page the ask needs, with its path and query, not the home page, and put the steps in the text. An office page is a path: `/tasks`, `/automations`, `/apps`, `/skills`, `/integrations`, `/settings`, `/inbox/asks`, or an Integrations tab: `/integrations/providers` (Claude and Codex sign-in), `/integrations/mcp`, `/integrations/secrets`, `/integrations/variables`, `/integrations/voice`, `/integrations/browser` (Chrome pairing), `/integrations/github` (owners only), `/integrations/pager`, `/integrations/api-tokens`, `/integrations/messaging`. `/agents/<agentId>` opens an agent's chat in a room the member can reach. `/inbox/asks/<askId>` opens one ask, open or closed. The same paths on the office's web address work as plain links.
