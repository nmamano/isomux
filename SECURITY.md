# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Email `llc@isomux.com` with the subject `Security report`. Include the affected
version, the impact, steps to reproduce, and any suggested fix. Do not include
credentials or private customer data unless we ask for them through a secure
channel.

Nil Mamano owns the response. He will acknowledge the report, assess it, and
coordinate a fix and release. We do not publish a response-time promise yet.

## Supported versions

Isomux uses a rolling release channel. Security fixes ship in a new CalVer
release whose GitHub Release carries a machine-readable security marker. The
owner still chooses when to apply each release.
