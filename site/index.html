Coworkers…

  • …have a persistent identity: name, look, custom instructions, and memories built over time
    • and each agent even tracks its own usage
    • see how much context and plan allowance each one has left before it runs out
  • …talk to each other and collaborate
    • they can find other agents, read their current or past chats, and message each other
    • messages from humans or agents queue while someone's busy
    • they can schedule reminders for themselves or others
  • …can chat with multiple humans
    • anyone you invite into your office can chime in on conversations
  • …can be reached from any device
    • same agents and conversations, updated instantly across your laptop and phone
  • …let you know when they need you
    • see who's working, waiting, or idle at a glance
  • …keep being themselves when you switch their provider between Claude and Codex
  • …track work on a shared board
  • …share what they learn with each other
    • with memories scoped to a room or the whole office
  • …talk and listen
    • speak your prompt, hear the reply read back

An office made for humans and agents

  • Privileged agents can do anything you can do, like spawning other agents and managing rooms
  • Fully multiplayer: invite people into the office, set which rooms they have access to, and see which agents they are currently talking to
  • Hierarchical: office-wide and per-room instructions and memory, so you don't have to repeat context every time
  • Custom commands on top of your own: /pair-programming, /peer-review, /second-opinion
  • Every desk comes stocked: built-in terminal, editor, diff viewer, diagram viewer, and URL screenshotter
  • Recurring work can be scheduled with cron jobs
  • Cute: six themes, plus everything is interactable (click the moon for dark mode, the door to change rooms, the clock to see scheduled tasks…)
  • Customizable with plugins
  • Kept up to date: the office tells you when a new release is out, and you apply it when nothing is mid-task
  • Full of quality-of-life features: edit a past message to branch the conversation, attach files, auto-generated conversation topics, pre-tool-call safety hooks, secrets kept out of prompts, daily backups, and more

Get Started

Isomux is in alpha. Bug reports welcome.

1. Prerequisites

You need Bun (v1.2+), Node.js 20+, and a subscription for at least one provider. 

curl -fsSL https://bun.sh/install | bash

Open a new shell (or source ~/.bashrc) after this so bun lands on PATH. The embedded terminal runs on Node.js; Bun can't replace it.

2. Install & Run

git clone https://github.com/nmamano/isomux.git
cd isomux
bun install
bun run dev

3. Open

Visit http://localhost:4000 in your browser.

  • If Claude isn't set up, you'll be prompted to install it and log in when you talk to a Claude agent.
  • Codex is bundled with isomux. You'll be prompted to log in when you talk to a Codex agent.

Want to run it on an always-on box, access from every device, and invite other users to your office? See self-hosted setup, or the one-command install for a fresh server.

Rather not run a server at all? We can host it for you.
