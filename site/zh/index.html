为人类和智能体打造的办公室

  • 特权智能体可以执行你能执行的任何操作，例如创建其他智能体和管理房间
  • 多人协作：邀请他人进入办公室，设置每人的房间访问权限，并查看他们正在与哪些智能体交谈
  • 分层管理：办公室和房间分别设置指令与记忆，无需每次重复上下文
  • 每个工位都配备工具：内置终端、编辑器、差异查看器、图表查看器和网页截图工具
  • 重复性工作 可以定时运行
  • 可爱：六种主题，各处均可交互（点击月亮切换深色模式，点击门切换房间，点击时钟查看定时任务…）
  • 丰富的便利功能：编辑旧消息以创建对话分支、添加附件、自动生成对话话题、工具调用前的安全钩子、避免将机密信息放入提示词、每日备份等

开始使用

Isomux 处于 alpha 阶段。 欢迎报告缺陷。

1. 前提条件

需要 Bun （v1.2+）、 Node.js 24（LTS），以及至少一个受支持提供方的访问权限。 

curl -fsSL https://bun.sh/install | bash

完成后，请打开新的 shell（或执行 source ~/.bashrc），以便将 bun 加入 PATH。内置终端运行于 Node.js；Bun 无法替代它。

2. 安装并运行

git clone https://github.com/nmamano/isomux.git
cd isomux
bun install
bun run dev

3. 打开

在浏览器中访问 http://localhost:4000 。

  • 如果尚未设置 Claude，与 Claude 智能体交谈时会提示安装并登录。
  • Codex 随 isomux 提供。与 Codex 智能体交谈时会提示登录。
  • OpenCode 随 isomux 提供，需要 Linux。请选择免费、按量付费或订阅模型。

想在常开机器上运行，从所有设备访问，并邀请其他成员进入办公室？请参阅 自托管设置 ，可使用自己的硬件，也可在新服务器上执行无人值守的 VPS 安装。

不想自行运行服务器？ 我们可以提供托管服务。
