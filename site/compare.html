The tools

  • Omnigent, from Databricks, open-sourced under Apache 2.0 in June 2026. Its README lists Claude Code, Codex, Cursor, OpenCode, Hermes, and Pi.
  • qm, from Y Combinator, is a multiplayer agent harness in Slack and on the web, under the MIT License. Pi and Claude Code drive its core.
  • Orca, from Stably AI, is an agent development environment that runs Claude Code, Codex, OpenCode, Pi, and other CLI agents in parallel, with desktop apps and iOS and Android apps. It is MIT licensed.
  • Munder Difflin, by GitHub user chaitanyagiri, is a local multi-agent harness that runs Claude Code, Codex, OpenCode, Pi, and other agent CLIs as an office of agents at desks. It is MIT licensed.
  • OpenClaw is an open-source AI assistant that runs on your own computer and talks to you through apps such as Discord, Slack, Telegram, and WhatsApp. Peter Steinberger and the community built it; the OpenClaw Foundation develops it under the MIT License.
  • Hermes Agent is a self-improving AI agent from Nous Research, reachable from the CLI, Telegram, Discord, Slack, WhatsApp, and Signal. It is MIT licensed.
  • Pi is a minimal agent harness that Mario Zechner started in 2025, now from Earendil Inc. under the MIT License.
  • AdaL, from SylphAI, is an automation-first agent harness named after Ada Lovelace. It works with Claude, GPT, Gemini, and local models, among others.
  • Cursor is a coding agent from Anysphere, which SpaceX acquired in August 2026.
  • Grok Bot is a team of always-on agents from SpaceXAI, launched in August 2026 for SuperGrok and Cursor subscribers.
  • Muse is a personal AI agent from Meta, rolling out in the US since September 2026 on iOS, Android, and muse.ai. It is free for most uses, with subscription plans.
  • Conductor, from Melty Labs, is a Mac app that runs many coding agents in parallel on one codebase. Its paid cloud workspaces let a team open the same chats.
  • Claude Squad is a terminal app that runs Claude Code, Codex, Gemini, and other agents in separate tmux sessions and git worktrees. It is AGPL-3.0 licensed.
  • Vibe Kanban, from Bloop, plans work as kanban issues and runs coding agents in workspaces. Bloop announced its shutdown in April 2026; the Apache 2.0 project continues, maintained by the community.
  • Claude Code agent teams is an experimental Claude Code feature, off by default. One Claude Code session leads a team of others, which share a task list and message each other.
