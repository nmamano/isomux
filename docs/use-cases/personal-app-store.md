# The personal app store

Agents build apps for you on the spot, such as a to-do list or a dashboard. Isomux runs them 24/7 behind your office sign-in and lists them on the Apps page. You use an app through its interface or by chatting with its agent, and the app can message the agent back.

<img class="diagram diagram-light diagram-narrow" src="/use-cases/agent-app-loop.svg" width="909" height="598" alt="A four-node loop. The user sends natural language inputs to the agent and gets natural language outputs back; the user sends interactive inputs to the just-in-time app and gets interactive outputs back. The agent writes the app's implementation and the app sends the agent notifications. The agent maps natural language requests to structured state updates and reads back data to base answers on; the app writes state updates and reads back data to display.">
