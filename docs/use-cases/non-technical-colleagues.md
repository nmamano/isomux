# Agents for non-technical colleagues

Engineers and non-technical colleagues ("normies") share the same agent conversations in real time. Engineers set up the agents, colleagues chat with them, and engineers step in when colleagues get stuck. Agents build apps such as dashboards, and colleagues open them with their office sign-in.
